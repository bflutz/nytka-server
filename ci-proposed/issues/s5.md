# Homley VM deployment: Compose file, loopback bind, Tailscale serve, no Drive backup

Phase 1 ([plan](https://github.com/bflutz/nytka-server/blob/phase1/docs/voice-recorder-plan.md), §4, §5). Nytka runs in a new Proxmox VM on Homley (proposed VM 240 'nytka': Debian 13, 2 vCPU, 4 GB RAM, 32 GB system disk, plus a 100 GB audio disk), with Docker Compose inside the VM. Homley's existing containers stay untouched. The phone reaches it only over Tailscale at `https://nytka.tail143365.ts.net`. Recordings stay local and never go into the Google Drive backup.

**Change:**
- Add `deploy/homley/` with:
  - `docker-compose.override.yml`: published on 127.0.0.1:8080 only, Postgres with no port, audio on `/srv/nytka/audio`
  - `.env.example`: BMain URLs as placeholders, retention 3650, no secrets
  - `tailscale-serve.md`: `tailscale serve --bg 8080`, tag `tag:nytka`
  - `README.md`: the VM spec, the firewall (inbound only from tailscale0; outbound only to BMain :8000/:11434, CT 110 :8080, Tailscale and package mirrors), a nightly `pg_dump` to the VM's own disk, and a clear note that audio and dumps stay out of restic/Drive
- Change no production code.
