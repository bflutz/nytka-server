# GPU-use check: prove STT and the LLM really run on BMain's GPU

Phase 1 ([plan](https://github.com/bflutz/nytka-server/blob/phase1/docs/voice-recorder-plan.md), §4 'GPU-use verification'). Community lesson: setups fall back to CPU silently. BMain has an RTX 4070 Ti SUPER (16 GB). Video Logs measured large-v3 at 7.8 min of audio in 40 s there.

**Change:**
- Add `tools/gpu-check/`:
  - a PowerShell script for BMain that prints `nvidia-smi` (STT and Ollama processes plus VRAM) and `ollama ps` (expects `100% GPU`)
  - a cross-platform script that sends a fixed 60 s test WAV to the STT URL and times it
- Add a timing check to the server's STT probe (see the backlog issue): record each batch's audio-seconds per wall-second, and report `slow` in the status when it drops below a threshold `Nytka__Stt__MinSpeedup` (default 5).

**Done when:**
- The scripts run without admin rights and change nothing.
- The test WAV is generated in the repo (synthetic tone or speech-free noise plus a public-domain clip), with no real recordings.
- The status shows the speed-up; a test covers the `slow` flag.
